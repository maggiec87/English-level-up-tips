## 为 初学者单词表 做贡献

请直接将 单词 添加至本 repo 目录： **[word-list](word-list)** 下对应的 md 文件中，不需要添加单词的解释，注意换行+空行（参照每个 md 文件的前两个单词）。

在生词数量接近完善时会统一输出带有中文释义的版本，并会在后期进行补充解释。
